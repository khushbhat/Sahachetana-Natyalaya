### Identification and consent

- Photographs do **not** name dancers. The exception is `sahanaPerformance`, attributed to Guru
  Vidushi Sahana Chethan because it was taken on the same day, with the same camera and in the same
  costume as her supplied portrait. It carries a "To be verified" badge until confirmed.
- Entries with `includesMinors: true` in `images.ts` show recognisable children. **Confirm guardian
  consent before launch**; to withdraw a photograph, remove its uses (search for the key) — the
  gallery and festival record adapt automatically.
- `bharatiyamGroup` is a 720 px WhatsApp copy. Ask for the original file; it is shown small until then.

## Adding or replacing a photograph

1. Put the original under `images/` (any subfolder).
2. Add a crop to `CROPS` in `scripts/optimize-images.py`:
   `"name": ("images/folder/FILE.JPG", (left, top, right, bottom))` as fractions of the image.
3. Run `npm run images` — it prints each crop's aspect ratio and generated widths.
4. Add an entry to `photos` in `src/data/images.ts` with the same `base`, the printed aspect,
   accurate alt text, and `includesMinors: true` where relevant.
5. Reference it from content data (`gallery.ts`, `events.ts` → `photos`, `founders.ts` → `portrait`/`secondary`,
   `awards.ts` → `certificate`, or a section in `HomePage.tsx`).

`image: null` renders a framed, labelled placeholder; a missing file falls back to the same placeholder.

## Official logo — still needed

No logo file was found in the supplied folders. The header, footer and favicon use a **temporary
typographic wordmark** (`src/components/ornaments/Wordmark.tsx`, `public/favicon.svg`). To use the
official logo: place an SVG (preferred) or a 512 px+ transparent PNG in `public/`, render it in
`Wordmark` in place of `WordmarkMotif`, and replace `favicon.svg`. Keep its proportions and clear space.

## Vector ornaments (hand-drawn SVG, `src/components/ornaments/`)

All take their colours from theme tokens (`--ornament`, `--bell-fill-1/2/3`), so they work in both themes.

- `Ghungroo` — bell with ring, beaded collar, granulated seam and slit mouth (anklet rail, venue markers, edition strand, lists).
- `Pendant` — temple-jewellery terminal for the anklet rail.
- `Hoysala` — stepped plinth `Corner`/`CornerFrame`, lotus `Rosette`, 16-point `Stellate`, `Pillar`, `Finial`, `MudraMark` (Alapadma, Mukula, Pataka).
- `ArchFrame` — cusped multifoil arch (hero, portraits).
- `Divider` — rosette and gejje variants.
- `Adavu` — **new**: `AdavuFoot`, a single-line drawing of a foot struck flat (tattadavu) with its anklet,
  which draws itself in when scrolled into view; `ArchiveLabel`, the small catalogue card used beside photographs.
- `Wordmark` — temporary, see above.
